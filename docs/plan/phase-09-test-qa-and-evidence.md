# Phase 09: Test, QA, and Evidence

- Status: Planned
- Depends on: Phase 01 through Phase 08
- ADRs: ADR-0001, ADR-0017

## Goal

Build the test pyramid, deterministic fixtures, Real App checks, manual QA, and evidence trace.

## Tasks

- [ ] Create domain, persistence, platform, services, features, UI, integration, and acceptance targets.
- [ ] Create fixture server/proxy state machines and JSON scenarios.
- [ ] Emit readable human logs and normalized typed trace events.
- [ ] Run CI smoke on arm64 and universal verification.
- [ ] Execute Real App, accessibility, filesystem/process, provider, proxy, backup, and release QA.
- [ ] Link evidence to every parity row.

## Exit criteria

No matrix row lacks applicable evidence and skips are distinguishable from failures.
