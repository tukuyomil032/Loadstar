# LoadStar Design Documents

This is the active requirements and implementation-design surface for LoadStar.

- ADR-0001 through ADR-0017 are the consolidated architecture and product decisions.
- decision-ledger.md is the decision summary and supersession map.
- feature-parity-matrix.md is the reference behavior and evidence inventory.
- open-decisions.md contains only remaining implementation gates.
- question-progress.md records requirements progress.
- plan/ contains exactly one file for each Phase 00 through Phase 10.

## Reading order

1. decision-ledger.md
2. feature-parity-matrix.md
3. open-decisions.md
4. question-progress.md
5. Relevant ADR
6. plan/README.md

## Rules

ADRs explain why. Plans explain implementation order and exit criteria. Reference facts, decisions, inferences, and evidence remain separate. Update a consolidated ADR or the canonical Phase file instead of creating duplicate addenda. Historical files deleted from the repository are not part of the active documentation surface.
